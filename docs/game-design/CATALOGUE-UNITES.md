## Unités

`i` est l’indice stable dans `_unites`, **pas** le champ `id` facultatif. I = infanterie, R = tireur, C = cavalerie. G = or, w = bois, o = minerai, m = mercure, c = cristal, s = soufre, g = gemme. Production = valeur brute du catalogue, traditionnellement quotidienne; absente = inconnue/non applicable.
